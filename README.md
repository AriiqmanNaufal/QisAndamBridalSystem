#💍 Wedding Planning System – Qis Andam Bridal

A web-based wedding planning system designed to simplify and streamline the wedding organization process. Built with PHP, CSS, and MySQL, this platform helps users manage guest lists, budgets, vendors, schedules, and more — all in one place.

✨ Features

👥 Manage guest lists and RSVPs

🗓️ Create and track wedding schedules

📋 Vendor management (e.g., catering, makeup, decoration)

💰 Budget planning and expense tracking

🎁 Wedding gift crowdfunding module

📧 Email notifications (e.g., reminders, invitations)

🛠️ Tech Stack

Frontend: HTML, CSS

Backend: PHP

Database: MySQL

APIs Used: Google Calendar API, SendGrid API
